Project & program controls talent

What We Support

Keep programs on cost and on schedule

Program controls is where finance meets execution. Our consultants build and maintain baselines, run earned value analysis, and turn cost and schedule data into reports your program managers and customers can act on.

Whether you need to stand up an EVM system for a new award, prepare for an Integrated Baseline Review, or just get monthly reporting back on time, we can send someone who has done it before.

Roles we place

  • Program control analysts
  • Project schedulers / planners
  • Earned value (EVM) analysts
  • Program financial analysts
  • Project accountants
  • Program control managers
